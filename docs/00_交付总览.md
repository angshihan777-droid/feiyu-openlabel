## 业务主链

管理员上传视频 → 创建批次并配置标注员池/审核员池 → 系统自动轮询分配标注任务 → 标注员提交时间段 → 系统自动分配审核员 → 审核通过或驳回 → 第 3 次驳回升级管理员 → 管理员裁决 → 按 UTC 提交日统计有效时长并导出 CSV。

核心约束：

- 租户之间数据和文件严格隔离。
- 标注员、审核员在同一批次内必须角色分离。
- 标注员与审核员双向匿名，管理员可见真实身份。
- 任务由系统自动分配，不依赖手工领取。
- 区间采用左闭右闭 `[start, end]`，触点也算重叠。
- 原标注员承接驳回任务；第 3 次驳回升级管理员。
