# 规格与接口契约

## SDD 契约来源

本实现的规格来自 `C:\Users\ashia\Desktop\SaaS\改造方案` 的 15 份文档，以及用户后续明确选择：

- 角色分离
- 双向匿名审核
- 自动轮询分配
- 左闭右闭区间
- 第 3 次驳回升级
- 后端转存视频
- 单文件 500MB
- 先按 UTC 统计日期
- 不修改既有核心接口路径和载荷

文档中个别旧示例与最终决策冲突时，以用户最终决策为准。例如旧示例写 `end > next.start`，最终实现采用 `end >= next.start`。

## 数据契约

### Unit 状态

| 状态 | 含义 | 下一状态 |
|---|---|---|
| `assigned` | 已自动分配给标注员 | `under_review` |
| `in_progress` | 标注处理中 | `under_review` |
| `under_review` | 已提交并分配审核员 | `approved` / `rejected` / `escalated` |
| `rejected` | 驳回给原标注员 | `under_review` |
| `escalated` | 多次驳回后待管理员裁决 | `approved` / `assigned` / `difficult_sample` |
| `approved` | 终态通过 | 无 |
| `difficult_sample` | 管理员标记困难样本 | 后续人工处理 |

### 时间段

输入与输出统一为：

```json
{
  "start": 0,
  "end": 5.2,
  "label": "抓取"
}
```

规则：

- `start`、`end` 必须为有限数字。
- `start >= 0`。
- `end > start`。
- 有视频时长时必须满足 `end <= duration`。
- 区间按起点排序。
- 前一个区间 `end >= 后一个 start` 即重叠。
- 至少存在一个有效区间。

### 提交快照

每次成功提交生成 `TaskSubmission`：

- 保存标准化 intervals
- 保存 `total_duration`
- 保存 UTC `submission_date`
- 保存 label 版本
- 新提交将同一 Unit 的旧快照标记为无效
- 驳回和管理员重分配使当前快照失效
- 强制通过使最新快照重新有效

## API 契约

### 标注员

| 方法 | 路径 | 输入 | 输出/行为 |
|---|---|---|---|
| GET | `/api/v1/b/units/my-tasks` | Bearer token | 本人 `assigned/in_progress/rejected` 任务；审核员匿名 |
| GET | `/api/v1/b/units/{id}` | Bearer token | 任务详情；按查看者角色匿名 |
| POST | `/api/v1/b/units/{id}/submit` | `{intervals:[...]}` | 校验、快照、轮询审核员 |

### 审核员

| 方法 | 路径 | 输入 | 输出/行为 |
|---|---|---|---|
| GET | `/api/v1/b/units/my-reviews` | Bearer token | 本人待审任务；标注员匿名 |
| POST | `/api/v1/b/units/{id}/approve` | 空 JSON | 通过 |
| POST | `/api/v1/b/units/{id}/reject` | `{reason}` | 驳回；第 3 次升级 |

### 管理员

| 方法 | 路径 | 输入 | 输出/行为 |
|---|---|---|---|
| GET | `/api/v1/b/units/escalated` | Bearer token | 真实姓名、当前区间、完整驳回历史 |
| POST | `/api/v1/b/units/{id}/force-approve` | `{note}` | 强制通过并使最新快照计入统计 |
| POST | `/api/v1/b/units/{id}/reassign` | `{new_assignee_id,reason}` | 回到新标注员，驳回计数清零 |
| POST | `/api/v1/b/units/{id}/mark-difficult` | `{reason}` | 标记困难样本 |
| GET | `/api/v1/b/challenge/users/pools` | Bearer token | 当前租户标注员/审核员池 |
| GET | `/api/v1/b/stats/daily-duration` | `batch_id,start_date,end_date` | 按提交人、UTC 日期聚合 |
| GET | `/api/v1/b/stats/export` | `batch_id,start_date,end_date` | UTF-8 BOM CSV，含真实姓名 |

### 视频

| 方法 | 路径 | 输入 | 输出/行为 |
|---|---|---|---|
| POST | `/api/v1/b/media/upload` | multipart `project_id,file` | 分块落盘、500MB 上限、租户目录隔离 |
| GET | `/api/v1/b/media?project_id=` | Bearer token | 当前租户和项目的视频列表 |
| GET | `/api/v1/b/media/{id}/stream` | Bearer token 或 `?token=`、可选 Range | 200/206 视频流 |

允许扩展名：`.mp4 .mov .m4v .webm .mkv .avi`。

### 演示快捷身份

| 方法 | 路径 | 用途 |
|---|---|---|
| GET | `/api/v1/b/u/a/noau/demo-login/status` | 返回演示登录开关状态 |
| POST | `/api/v1/b/u/a/noau/demo-login/{identity}` | `tenant` / `annotator` / `reviewer` 测试身份登录 |

该能力默认关闭，只有环境变量 `FY_DEMO_QUICK_LOGIN=true` 时才签发测试账号 JWT。共享或生产环境不得开启。

## 兼容性边界

以下原核心接口保留：

- `/projects/*`
- `/taxonomies/*`
- `/labels/units/*`
- `/projects/{id}/batches`
- `/batches/{id}`
- `/projects/{id}/units`
- `/units/by-coord`
- `/units/{id}/claim|assign|release`

Challenge 路由是增量新增。`batches` 的列表过滤参数增加可选 `status`，原有参数没有改名。

## 幂等与并发

- label 写入使用 `expected_version` 乐观锁。
- `TaskSubmission` 对 `(tenant_id, unit_id, label_version)` 唯一。
- 租户查询始终带 `tenant_id`。
- 跨租户 Unit 查询返回 404，避免资源 ID 探测。
- 视频路径解析限制在租户目录内。
