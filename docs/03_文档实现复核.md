## 关键流程核对

### 上传

- 管理员按项目上传。
- 文件不进入进程内存整块读取，8MB 分块落盘。
- 应用层 500MB 限制，Nginx 请求体上限 600MB。
- 文件存入租户目录。
- 非所有者和跨租户访问不可达。
- 视频播放支持 HTTP Range。

### 创建批次

- 必须选择已上传视频。
- 固定 `videoEvents` 类型。
- 标注员池和审核员池来自当前租户 RBAC。
- 两池交集立即拒绝。
- 创建后自动 spawn，每个视频一个 Unit。

### 标注

- 标注员只看到自己的任务。
- 视频按任务 URL 加载。
- 动作、事件、场景都以明确起止时间记录。
- 名称/类别写入 `object_type` 和 OpenLABEL 属性。
- 前端先做闭区间与重叠校验，后端再次权威校验。
- 保存草稿走 label v2 乐观锁。
- 提交走 Challenge submit，生成不可变快照。

### 审核

- 提交后自动轮询审核员池。
- 审核列表不返回标注员 ID 或真实姓名。
- 若账号同时具备两个角色，也禁止审核自己。
- 驳回必须填写原因。

### 管理员

- 只列出 escalated。
- 显示真实标注员、审核员和全部驳回历史。
- 强制通过重新激活最新快照。
- 重分配清空旧快照、审核员和驳回计数。
- 困难样本使该任务不再计入有效时长。

### 统计

- 有效时长来自有效 TaskSubmission。
- 按提交人、提交日聚合。
- CSV 包含真实标注员、审核员、视频名、日期、时长、最终状态。
- 日期目前是 UTC。
